# Changelog

All notable changes to the **Lakshya Agarwal Portfolio** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-08-04

### 🚀 Added
- **Progressive Scrollytelling Engine**: 300-frame canvas sequence with two-tier `requestIdleCallback` progressive streaming and DPR retina scaling.
- **Arcade 2.0 Interactive Suite**:
  - *Pixel Football*: Retro striker mini-game with dynamic wind vectors, curve trajectory physics, and goalie AI.
  - *Tech Factory*: Cybernetic hardware manufacturing line with precision timing and purity scoring.
  - *Terminal Hacker*: Memory exploitation simulation with cipher decryption algorithms.
  - *The Developer Vault*: Locked easter-egg rewarding players with recruiter dossiers and 24K gold theme switcher.
- **Zero-Asset Procedural Audio Synthesizer (`arcadeAudio.ts`)**: 100% code-synthesized audio via native Web Audio API oscillators, sub-bass thuds, and noise filters.
- **D3 Global Communication Matrix**: Interactive orthographic globe projection with velocity inertia, vector hubs, and `IntersectionObserver` frame loop gating.
- **Edge Security & Anti-Abuse**: Next.js Edge Middleware with strict Content Security Policy (CSP), sliding-window IP rate limiter, and honeypot bot trap on `/api/reward`.
- **WCAG 2.2 AA Compliance**: Full keyboard navigation support (`Tab`, `Enter`, `Space`, `1-4`, `Escape`), ARIA live status announcements, and high-contrast color tokens.
- **Fine-Pointer Tactile Cursor**: Magnetic halo cursor with physical mouse-down compression and smooth spring physics scoped strictly to `(pointer: fine)` devices.

### ⚡ Changed
- Upgraded project to **Next.js 14 App Router** with full TypeScript 5.0 strict type coverage.
- Standardized all contact protocols and mail links to `contact@lakshya.uk`.
- Optimized hardware-accelerated CSS layers with scoped backdrop blur filters and GPU compositing hints.
- Dynamic project card header theming adapting automatically to project color accents (Cyan, Emerald, Amber).

### 🔒 Security
- Added strict HTTP response security headers: HSTS Preload (`max-age=63072000`), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, and strict CSP directives.
- Protected email dossier delivery with in-memory sliding-window token bucket rate limiting.
